ekiliRelay is a free email-sending API for developers inside the [ekilie](https://ekilie.com) ecosystem. Transactional email (verifications, receipts, notifications) should be one HTTP call, not a week of SMTP debugging.

## What it does

- REST API for sending transactional email
- Built for developers: API keys, simple payloads, clear errors
- Powers production mail for ekilie products including [Magreth](/projects/magreth/) and [Transliflow](/projects/transliflow/)

Live at [relay.ekilie.com](https://relay.ekilie.com).
