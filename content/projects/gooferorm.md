GooferORM is an ORM for Go built for speed and predictability: define models, run migrations, build queries, and always know what SQL you are generating. It grew out of real production pain with heavier ORMs across the [ekilie](/projects/ekilie-cloud/) ecosystem and side projects like [BeamDrop](/projects/beamdrop/).

## Design goals

- Explicit over magical: the SQL is always inspectable
- Fast paths for bulk inserts and reads
- Migrations as code, runnable in CI
- Docs and examples at [gooferorm.vercel.app](https://gooferorm.vercel.app/)

Open source at [github.com/gooferOrm/goofer](https://github.com/gooferOrm/goofer.git).
